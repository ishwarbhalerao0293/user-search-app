# 👥 User Search App

A responsive React application that fetches and displays user information from an API, with real-time search functionality.

## ✨ Features

- Fetches user data from an API
- Real-time search by user name
- Displays username, email, company, and city
- Loading indicator while fetching data
- Error handling for failed API requests
- No-results message when no users match
- Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS3
- Vite
- React Hooks (`useState`, `useEffect`)
- JSONPlaceholder API

## 🌐 API

This project uses the JSONPlaceholder Users API:

https://jsonplaceholder.typicode.com/users

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ishwarbhalerao0293/user-search-app.git
```

### 2. Navigate to the project folder

```bash
cd user-search-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the app.
